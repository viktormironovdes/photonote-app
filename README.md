# PhotoNote 📸

**Личная база знаний фотографа**

Версия: **0.1.1** — EXIF-метаданные

Приложение для хранения референсов, схем света, оборудования и шпаргалок. Всё работает локально, без интернета.

---

## 📦 Что используется в проекте

| Компонент | Версия | Для чего |
|-----------|--------|----------|
| **Capacitor** | `^8.0.0` | Превращает веб-код (HTML/CSS/JS) в нативное Android-приложение |
| **@capgo/capacitor-file-sharer** | `^8.0.0` | Сохранение файлов через нативное окно Android (экспорт данных) |
| **exif-js** | `2.3.0` | Извлечение EXIF-метаданных из фотографий (камера, ISO, диафрагма, выдержка) |
| **HTML + CSS + JS** | — | Интерфейс приложения (чистый код, без фреймворков) |
| **localStorage** | — | Хранение всех данных на устройстве |

## 📷 EXIF-метаданные

При добавлении референса можно нажать кнопку **"📷 Извлечь EXIF"** — приложение автоматически прочитает из фотографии:

- 📷 **Модель камеры** (Make + Model)
- 🔭 **Объектив** (LensModel / Lens) — если есть в метаданных
- 📐 **Фокусное расстояние** (FocalLength)
- 🎯 **Диафрагма** (FNumber)
- ⏱️ **Выдержка** (ExposureTime) — автоматически форматируется (1/125, 1/250 и т.д.)
- 📊 **ISO** (ISOSpeedRatings)
- 📅 **Дата съёмки** (DateTime)

Все данные сохраняются в карточке референса и отображаются при просмотре в слайдере.
